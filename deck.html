The solution

GitHub Copilot SDK

One npm package. Deploy your agents as a service.

What It Is

  • @github/copilot-sdk — npm package, open source
  • Spawns a CLI subprocess that runs the full agent loop
  • Manages sessions, streams events in real-time
  • Built-in tools: grep, view, glob, bash
  • Define custom agents with specialized prompts and tool restrictions
  • You control the UX, the auth, and the deployment

What It Resolves

Individual Copilot license → GitHub OAuth + org API billing
VS Code / CLI required → Any browser, any device
Personal token consumption → Centralized org billing
Developer-only access → PMs, leads, new hires — anyone

Under the hood

Key Code Highlights

Three pieces that make it work

1. Client & Session

const client = new CopilotClient(); await client.start(); const session = await client.createSession({ model: "claude-haiku-4.5", workingDirectory: repoPath, customAgents: CUSTOM_AGENTS, onPermissionRequest: async () => ({ kind: "approved" }), });
CopilotClient spawns a CLI subprocess. Each session binds to a repo directory.

2. Custom Agents

const CUSTOM_AGENTS = [ { name: "explorer", tools: ["grep", "glob", "view"], prompt: "You are a code exploration expert..." }, { name: "analyzer", tools: ["grep", "glob", "view"], prompt: "You are a code analysis expert..." }, { name: "architect", tools: ["grep", "glob", "view"], prompt: "You are a software architect..." }, ];
Each agent gets a restricted toolset and a specialized system prompt.

3. Event-Driven Streaming

// Subscribe to all session events and stream to browser via SSE session.on((event) => { res.write(`data: ${JSON.stringify(event)}\n\n`); // real-time to browser }); await session.sendAndWait({ prompt: question }, 300000);
The agentic loop is fully observable. Every tool call, every LLM decision, streamed to the UI in real-time.
